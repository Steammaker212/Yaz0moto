# Unreleased

## Features
- **Check Level** (Area menu, Ctrl+Shift+K): lists likely mistakes in the open level without blocking anything, such as warps to entrances that don't exist, duplicate entrance IDs, a missing start entrance, sprites or entrances outside every zone, overlapping zones, a wrong number of Star Coins or two Star Coins with the same number, more than one checkpoint, sprites that point at a path, location or entrance that doesn't exist, movement/event IDs nothing else uses, paths with one node, duplicated sprites and walking enemies with no ground below them. Double-click a problem to select it. The rules are in `yaz0data/levelcheck_rules.json`; *Edit rules...* makes your own copy to change
- The Check Level window's **Metrics** tab counts sprites, enemies, Star Coins, checkpoints, entrances, paths and objects, and compares them with every original course in your game folder (median, and how many courses are below this level)
- **Export Mod Package** (File menu): saves the level and writes a `.zip` laid out like the game's folders (`romfs/Course`, plus the tilesets you made or changed in `romfs/Unit` for Deluxe) with a manifest listing each file's size and SHA-256
- **Undo History** window (View menu): shows every step that can be undone; click one to go back or forward to it
- **Preview Movement** button in the actor properties of any actor with a Movement ID: animates the actors hooked to the same movement controller (only in the same zone, as in the game), with a dashed line showing the route. Swaying and spinning rotation (68, 69, 116, 118) use the game's formulas and speeds, the same as Preview Pivotal Rotation; paths (100) follow the nodes, node speeds and delays, the default "curly" movement (or straight lines with Move strictly), Smooth movement, the sine effect, the starting node and what happens at the last node; two-way (70, 642), bolt (238, using each object's own direction, speed and distance multiplier) and stepped rotation (214, 484) controllers are supported too. Nothing in the level is moved
- The preview speed can be changed next to the button (0.5x to 8x; 1x is the game's speed, 2x by default) and is remembered
- **Movement preview options** (Options next to the button, or View > Movement Preview Options; shared by both previews): *Play Once* plays the movement one time instead of looping and ends the preview when every actor has finished; *Show Start Position* and *Show End Position* keep a faint copy of each actor, outlined in green or red, where it starts and where it ends (or turns back). While a preview plays, the real actors are hidden so only the moving copies show
- **Preview All Movement** (View menu, Ctrl+Shift+M, optional toolbar button): animates every movement controller in the area at once, and keeps going while you select things
- **Export All Tilesets**: Area > Export All Tilesets copies every tileset the level uses into a folder (exactly as saved), and the tileset editor's File > Export All Tilesets exports all open tilesets including unsaved changes
- **New look:** the Yaz0moto theme, after the Yaz0moto logo: flat charcoal surfaces with an orange accent, rounded minimal controls, and a new set of 82 icons drawn as SVG (sharp at any size, with a soft shadow). It is now the default; the other themes are still in Preferences > Themes. The icons are generated by `tools/theme_icons.py`
- **Legacy theme** (Preferences > Themes): the look from before the Yaz0moto theme, with the Neon colours that were the default, plain controls, the original icons and 16 px toolbar icons (picking it in Preferences picks that size too). The few icons the original set never had are drawn in its style by `tools/legacy_theme_icons.py`
- **Classic themes:** the Legacy theme is the base of classic themes, the way the Yaz0moto theme is of the modern ones: a classic theme sets `base="Legacy"` and its accent, background, text and level colours, and gets the original controls and icons in those colours (the accent colours the selection, zones, actor boxes and the overview). Bundled: Legacy Cavern, Legacy Dark, Legacy Dark Red, Legacy Night Mode, Legacy RVLution Red, Legacy Sky, Legacy Underwater and Legacy Volcano, the original themes with their own level colours. The modern themes are unchanged
- **Real View** has a toolbar button (next to the grid and live background buttons)
- **Themes are built on the Yaz0moto theme:** every bundled theme now uses its shapes and icons in its own colours (accent, background, text), keeping its own level view colours. Light themes work too
- **Theme Editor** (Preferences > Themes > Create Theme...): pick an accent, background, text and level colour and how round things are, with a live preview, and save your own theme. *Style* picks a modern theme or a classic one (the original controls and icons; starting from a classic theme picks it)
- **Bigger, rounder interface:** toolbar icons are 24 px by default (Preferences > Themes > Toolbar icons: 16 to 40 px) and controls are rounder
- **Parts bar** (View > Parts Bar), after Super Mario Maker's: your recent tileset objects and actors as big tiles on their own row under the main toolbar. Click one to paint with it or drag it onto the level; the orange button shows every part (each tileset, and the actors with a search box). Parts you pick in the palette are added to it, and the actor or object selected in the level is marked on it (added if it isn't there). The button at the right of the menu bar shows or hides it
- **Actors as icons** in the Add Actors palette (toggle next to the search box): each actor's sprite image, or a PNG named after its ID in the active patch (`patches/<patch name>/icons/<actor id>.png`), or the no-image picture (`yaz0data/sprites/no-image-sprite.png`) with its name. Actors can be dragged from here onto the level too
- **Icons for one setting of an actor:** in the level, `icons/<actor id>-<raw data>.png` (e.g. `59_0000-0000-0000-1000-0005-0000.png` for a ? block with a hammer; a dash, no dashes or lower case work too) is drawn instead of the actor's sprite image when both its ID and raw data match, and instead of `icons/<actor id>.png` for actors with no sprite image, and changes icon as its settings change. Info... in the right-click menu shows the file name for the actor's current data
- Click the star on the welcome page (or in the About box)
- **Legacy mouse controls** (Preferences > Editor), for the level view only: right click places the picked part or tool anywhere (dragging to size it) and, with nothing picked, deselects what's under the cursor (or everything on empty space); left click selects and drags; Shift + right click shows a thing's menu; Ctrl + right click the zone menu, as before
- **New mouse controls:** pick a part with a left click (in the palette, the actor icons or the parts bar), then left click on empty space in the level to place it, dragging to size it (a click on a thing selects or deselects it instead, and deselecting one, such as the thing just placed, also puts the part down; Alt+click places on top of things); click the picked part again, press Esc or right-click empty space to put it down. Left click selects a thing (clicking a selected thing again deselects it) and dragging moves the selection around. With nothing picked, on empty space a click deselects everything, a drag draws a selection box, and holding the button still (or double-clicking) deselects everything and scrolls the view as you drag. Right click on anything selects it and shows what it is (actor name and ID, object and tileset, entrance type...) with its actions. The entrance, path, location, comment and Nabbit path tools place on empty space and select things when clicked on them. The cursor is a crosshair where a click places the picked part

## Changes
- The properties panel is now in the right sidebar (it can still be dragged out to float; a floating one from before is moved there once). Clicking an actor, entrance, location or path node opens it there; placing a thing or drawing a selection box doesn't (they update it while it's open). It stays open when you click empty space, saying nothing with settings is selected; **Settings...** in a thing's right-click menu opens it again after it's closed
- Right-clicking an actor also shows **Info...** (name, ID, position, zone, layer, raw data and notes), and actors get Copy, Cut and Duplicate there like other things
- Dragging a selection box selects what it passes over without showing tooltips
- Actors without a sprite image show their patch icon (`patches/<patch name>/icons/<actor id>.png`) in the level instead of the box with their ID, drawn slightly larger than the box; clicking anywhere on the icon selects the actor and shows its properties
- **Esc** closes the window or menu in front, like its X button (the properties window first, from the level view), then puts down the picked part. It never closes the editor
- **Live Background** and **Animate Live Background** now have toolbar buttons (next to the grid button) and can be turned on or off under Preferences > Toolbar. Toolbar buttons added in an update now show up for people who customised their toolbar before
- The updater also understands release tags like `release-1.2.0` or `Yaz0moto-v1.2.0`, and a failed automatic update check is shown in the status bar instead of being ignored
- The release workflow refuses versions that are not `X.Y.Z`, which the updater could not compare
- Clips are exported as `.yaz0clip` files. Import Clip still opens `.miyaclip` files from older versions and other editors
- The recovery copy of an unsaved level is written every minute instead of every 20 seconds, and a "Saved to temporary file" message shows at the bottom left for a few seconds each time
- Changing the theme, style, UI scale, toolbar, actor notes or info icons, or turning mods on or off in Preferences, asks to restart Yaz0moto (**Restart Now** or **Restart Later**) and opens the level again where it was (same file, same area, unsaved changes kept). Unsaved tileset changes are saved first. Undo history starts fresh after the restart

# Yaz0moto v1.0.0

Yaz0moto is a fork of Pyamoto by Steammaker212 that adds full support for New Super Mario Bros. U Deluxe (Switch).

## Features
- Added New Super Mario Bros. U Deluxe as a base game. Pick it in the setup wizard or under Preferences > Game Setup, and point it at the `Course` folder of your dumped game; the `Unit` folder must be next to it
- Deluxe levels are read and written as little-endian `.sarc` files; opening a level from the other game offers to switch games, and changing game in Preferences starts a new level
- Deluxe tilesets are loaded from `Unit` (Yaz0 SARC with BNTX textures) and saved back there when edited
- The tileset editor works with Deluxe: it opens the exact tileset files the level uses, saves them into `Unit` (the shared main tileset asks before overwriting), exports and imports standalone `.szs` tilesets, and handles the block, `?` block, coin and conveyor animations
- In Deluxe mode the zone Background tab shows the real Deluxe file name (`dv_<name>.Nin_NX_NVN.szs`, in `romfs/Model`)
- The Choose Level window also lists level files that have no name (Deluxe ships over 100 of them, worlds 40-50)
- Miyamoto! DX settings are migrated into the Deluxe game slot

## Changes
- Renamed from Pyamoto to Yaz0moto: new name, icon and executable
- Your settings, mods and downloaded data are copied from the `Pyamoto` user data folder to a new `Yaz0moto` folder on first launch (the original is left untouched)
- The built-in updater now checks this project's releases instead of Pyamoto's
- Crash reports and the About box point to this project's GitHub instead of the Zenith Discord
- Builds and releases now run from the `deluxe-support` branch

## Fixes
- Fixed a crash when saving a level whose zone background has a parallax mode the dropdown doesn't list: the value is now kept and shown as "Unknown (n)"
- Fixed crashes on Python 3.10+ in sprites whose image size was a float
- Fixed the setup wizard writing a Deluxe path into the Wii U game slot, and the Game Setup tab always picking the first game with a valid path
- Fixed an error when switching from Deluxe to Wii U in Preferences
